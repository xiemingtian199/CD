# CD级产品赛马数据监控与判断程序

这是一个首版飞书多维表联动程序，用于支持：

选品假设 -> 上架测试 -> 数据反馈 -> 原因归类 -> 动作决策 -> 复测/淘汰/放量。

程序从飞书多维表读取“产品池、每日数据、规则配置”，按商品 x 渠道 x 日进行判断，并把建议结果写回“每日数据”表。程序只写建议和判断日志，不覆盖人工确认字段。

## 1. 表结构

建议在同一个飞书多维表中建立三张表。

### 产品池

| 字段名 | 说明 |
| --- | --- |
| 产品ID | 产品唯一标识 |
| 产品名 | 产品名称 |
| 品类 | 产品品类 |
| 平台 | 抖店、淘宝、快手、小红书等 |
| 渠道 | 直播、短视频、搜索、投放、自然流量等 |
| 负责人 | 负责人 |
| 测试批次 | 本轮测试批次 |
| 当前阶段 | 选品、上架测试、复测、淘汰、放量等 |
| 人工确认动作 | 人工最终确认动作 |
| 确认人 | 确认人 |
| 确认时间 | 确认时间 |

### 每日数据

| 字段名 | 说明 |
| --- | --- |
| 日期 | 数据日期 |
| 产品ID | 产品唯一标识 |
| 产品名 | 产品名称 |
| 品类 | 产品品类 |
| 平台 | 平台 |
| 渠道 | 渠道 |
| 曝光 | 曝光人数/次数 |
| 点击 | 点击人数/次数 |
| 加购 | 加购人数/次数 |
| 成交 | 成交订单数 |
| 成交金额 | GMV |
| 退款 | 退款订单数 |
| 竞品曝光 | 竞品曝光 |
| 竞品点击 | 竞品点击 |
| 竞品成交 | 竞品成交 |
| 竞品动销备注 | 人工备注 |
| 判断节点 | 程序写回 |
| 原因归类 | 程序写回 |
| 建议动作 | 程序写回 |
| 置信度 | 程序写回 |
| 命中规则 | 程序写回 |
| 判断日志 | 程序写回 |
| 判断时间 | 程序写回 |
| 人工确认动作 | 人工填写，程序不覆盖 |
| 确认人 | 人工填写，程序不覆盖 |
| 确认时间 | 人工填写，程序不覆盖 |

### 规则配置

每行可配置一个规则作用范围。更具体的配置优先级更高：平台 + 品类 + 渠道 > 平台 + 品类 > 平台 > 全局。

| 字段名 | 示例 | 说明 |
| --- | --- | --- |
| 平台 | 抖店 | 可空，空表示通用 |
| 品类 | 女装 | 可空 |
| 渠道 | 短视频 | 可空 |
| 最小曝光 | 300 | 样本门槛 |
| 最小点击 | 20 | 样本门槛 |
| 最小加购 | 5 | 样本门槛 |
| 最小成交 | 5 | 样本门槛 |
| 低点击率 | 0.01 | 低于该值判定视觉问题 |
| 低成交转化率 | 0.01 | 点击到成交偏低 |
| 低加购成交率 | 0.15 | 加购到成交偏低 |
| 高退款率 | 0.25 | 高于该值判定产品/承诺问题 |
| 竞品低成交率 | 0.005 | 竞品也卖不动 |
| 放量点击率 | 0.03 | 放量正向阈值 |
| 放量成交转化率 | 0.03 | 放量正向阈值 |
| 放量退款率上限 | 0.12 | 放量正向阈值 |
| 淘汰连续命中轮次 | 3 | 同类问题连续命中达到后建议淘汰 |

## 2. 本地配置

复制 `.env.example` 为 `.env`，填写飞书应用和多维表信息。

```powershell
Copy-Item .env.example .env
```

必填项：

```text
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_APP_TOKEN=
FEISHU_PRODUCT_TABLE_ID=
FEISHU_DAILY_TABLE_ID=
```

`FEISHU_RULE_TABLE_ID` 可先留空。留空时程序使用内置默认阈值；补齐 `规则配置` 表后再填入即可。

## 3. 运行

本地样例验证：

```powershell
python -m cd_racing_monitor --sample
```

真实飞书运行一次：

```powershell
python -m cd_racing_monitor --once
```

自动创建或补齐飞书表结构：

```powershell
python -m cd_racing_monitor --setup-feishu-schema
```

这个命令会在 `FEISHU_APP_TOKEN` 对应的多维表中创建/补齐 `产品池`、`每日数据`、`规则配置` 三张表，并输出三张表的 table ID。把输出的 ID 填回 `.env` 后，再运行 `--once`。

每天固定时间运行，例如每天 09:30：

```powershell
python -m cd_racing_monitor --schedule 09:30
```

## 4. 安全边界

- 程序只写回建议字段、命中规则、判断日志和判断时间。
- 程序不会覆盖 `人工确认动作`、`确认人`、`确认时间`。
- 样本不足时输出 `继续观察`，不做强判断。
- 飞书字段缺失或格式异常时，该记录会被跳过并输出错误日志。
